## 📌 Project Executive Summary
Developed an interactive financial risk evaluation system and executive dashboard evaluating **2,500+ loan applications** totaling **$32.08M in portfolio loan data**. Cleaned, transformed, and validated relational datasets using SQL, Excel, and Python to ensure strict regulatory reporting accuracy and portfolio stress testing.

## 🚀 Key Business KPIs & Risk Engineering
- **2,500+ Applications Evaluated**: Analyzed $32.08M in consumer and commercial loan applications.
- **81.0% Approval Rate / 19.0% Rejection Rate**: Classified applications based on credit scores (FICO), debt-to-income (DTI) ratios, income stability, and loan purpose.
- **Key Metrics Tracking**:
  - **$32.08M Total Loan Amount**
  - **$15,845 Average Approved Loan Amount**
  - **$65,988 Mean Applicant Annual Income**
- **Applicant Dossier Drill-Through**: Interactive filter slicers, risk grade classification (Grades A-F), and credit stress testing calculator.

## 🛠️ Tech Stack
- **Data Engineering**: Python (`pandas`, `numpy`), SQL (`MySQL`/`SQLite`), Excel (`VLOOKUP`, `Pivot Tables`, `Solver`).
- **BI & Visual Analytics**: PowerBI (`DAX`, Modeling, Dynamic Slicers), Chart.js, HTML5, CSS3, JavaScript.
